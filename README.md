# God's Eye Local (MVP)

A lightweight, CPU-friendly photogrammetry pipeline that converts raw monocular drone videos into 3D point clouds. This MVP is heavily optimized for Apple Silicon (M1/M2/M3) Macs, allowing you to bypass expensive GPU requirements by running Sparse Structure-from-Motion (SfM) entirely on your local CPU.

## Features

- **Automated Pipeline**: End-to-end processing from `.mp4` video to `.ply` 3D scene.
- **Pycolmap Integration**: Blazing fast CPU-based SIFT feature extraction and incremental 3D reconstruction.
- **AI Monocular Depth (Experimental)**: Uses HuggingFace's `DepthAnything-v2` to stitch monocular depth maps into dense scenes.
- **Interactive CLI**: Sleek terminal UI to guide you through mode selection and resolution limits.
- **Browser Viewer**: Includes a standalone `viewer.html` to instantly inspect your 3D point clouds locally.

## 🛠 Installation

### Prerequisites
- macOS (Apple Silicon recommended)
- Python 3.10+

1. **Clone the repository and navigate to it:**
   ```bash
   cd Desktop/godseyelocal
   ```

2. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *(This will install `pycolmap`, `opencv-python`, `torch`, `transformers`, and other necessary scientific libraries).*

## 🚀 Usage

### Option 1: Interactive CLI (Recommended)
Simply run the main script without arguments to launch the interactive wizard. It will automatically detect `.mp4` files in your folder.

```bash
python3 main.py
```

You will be prompted to:
1. Select your video file.
2. Select a Preset Mode (`FAST`, `BALANCED`, `QUALITY`).
3. Select a SIFT resolution limit (from `1024px` up to `4K`).

### Option 2: Command-Line Arguments
For automation, you can pass the arguments directly:

```bash
python3 main.py --input sample.mp4 --mode FAST --resolution 1920 --mesh
```

### Advanced Settings
You can tweak the internal engine parameters (FPS, feature extraction limits, matching windows) directly in `config.yaml`.

## 📊 Pipeline Stages

When you run the pipeline, it executes the following steps sequentially:

1. **Keyframe Extraction:** Analyzes the video and extracts perfectly spaced, non-blurry frames.
2. **SIFT Feature Extraction:** Finds thousands of unique visual anchor points in every image.
3. **Sequential Matching:** Tracks how those anchor points move across consecutive frames to understand the drone's flight path.
4. **Sparse Reconstruction (Pycolmap):** Calculates the exact 3D camera poses and triangulates a sparse point cloud.
5. **AI Dense Reconstruction:** Uses an AI depth model (`Depth-Anything-V2`) to predict per-pixel depth and generate a massive, dense point cloud.
6. **Artifact Export:** Saves the final models to the `outputs/<video>/scene/` directory.
7. **Poisson Surface Meshing (Optional):** Uses Open3D to calculate surface normals and wrap a solid video-game style mesh (`scene_mesh.ply`) over the dense point cloud.

## 👁️ Viewing Your 3D Scene

To view your reconstructed environment:
1. Double-click the `viewer.html` file to open it in your browser (Chrome/Safari).
2. Open your `outputs/<video_name>/scene/` folder.
3. Drag and drop the `scene.ply` (dense points), `scene_sparse.ply` (sparse points), or `scene_mesh.ply` (solid mesh) file directly into the browser window.
   - *Note: The viewer will automatically detect if you loaded a solid mesh and activate 3D studio lighting!*
4. Use your mouse to rotate and zoom around your 3D drone flight!

## ☁️ Next Steps: Achieving Photorealism

This pipeline successfully extracts the **exact 3D geometric camera poses**. This data is the "Holy Grail" starting point for state-of-the-art AI photorealism. 

To convert your sparse point cloud into a fully photorealistic environment (reflections, glass, water), you can hand off the data generated by this pipeline to a third-party GPU service:

1. Locate the `outputs/<video_name>/keyframes/` folder and `outputs/<video_name>/reconstruction/` folder.
2. Zip them together.
3. Upload them to **Luma AI**'s API or a cloud GPU running **Nerfstudio**.
4. They will train a 3D Gaussian Splat (`.splat` file) in ~15 minutes using the exact camera paths you calculated locally. 
5. Download the `.splat` file and view it at 60 FPS in any WebGL viewer!
